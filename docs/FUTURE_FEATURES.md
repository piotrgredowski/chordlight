# Future Features

Ideas collected from user and colleague feedback. These are backlog notes, not implementation commitments.

## Configurable guide position

Let users choose where the shortcut guide appears, with alignments such as top-center, top-right, or bottom. This could help keep it out of important content when recording the screen.

## Shortcut descriptions

Add an option to show a shortcut's description below its key combination.

## Configurable size

Let users adjust the guide's size.

Original colleague feedback (Polish):

> Dodaj opcję żeby móc ustawić np na górze na środku, albo wyrównane do prawej góry albo dołu. To może być przydatne do używania tego do nagrywania ekranu. Może też żeby tekst pokazywał się poniżej skrótu klawiaturowego. No i żeby wielkość była konfigurowalna.
