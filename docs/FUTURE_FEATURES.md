# Future Features

Ideas collected from user and colleague feedback. These are backlog notes, not implementation commitments.

## Implemented display controls

The panel now configures the guide's position, description placement, size,
stack spacing, history count and direction, duration, and history transparency.
These settings are stored with the other Chordlight preferences in TOML. Normal
direction keeps the current chord at the screen edge; inverted direction moves
it away from the edge while history extends toward it.

Original colleague feedback (Polish, implemented):

> Dodaj opcję żeby móc ustawić np na górze na środku, albo wyrównane do prawej góry albo dołu. To może być przydatne do używania tego do nagrywania ekranu. Może też żeby tekst pokazywał się poniżej skrótu klawiaturowego. No i żeby wielkość była konfigurowalna.

## App-specific custom shortcuts

Let users register custom shortcuts for specific applications and show each application's shortcut hints only while that application is focused.
